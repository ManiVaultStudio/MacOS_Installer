# Interface

- `index.html`: semantic page structure, navigation, and dialogs.
- `app.js`: UI state, API requests, compact pagination, and rendering.
- `styles.css`: shared design tokens, themes, layout, and motion.

The server serves these files directly with cache revalidation. Refresh the browser after UI changes; restart only after backend changes. Build workflow owns the project selector and its Project & plug-ins subview. Dependencies, Installers, and Activity are global. The header Create installer dialog is the main release action.
